# Учебник „Административни и офис дейности“

Уеб учебник за курс по професия „Административни и офис дейности“ (код 041501, I СПК), с. Чепинци, 2026/2027.
Работи на телефон, може да се инсталира като приложение и след първото отваряне с интернет работи и без интернет (уроци, задачи, тестове, график).

## Публикуване в GitHub Pages

1. Създайте ново хранилище (repository) в GitHub, например `uchebnik-aod`, с видимост **Public**.
2. Натиснете **Add file → Upload files** и качете **съдържанието** на тази папка (файловете, не самата папка). `index.html` трябва да е в главната папка на хранилището.
3. Натиснете **Commit changes**.
4. Отидете в **Settings → Pages**. В **Source** изберете **Deploy from a branch**, клон **main**, папка **/ (root)** и натиснете **Save**.
5. След 1–2 минути учебникът е на адрес `https://<вашето-потребителско-име>.github.io/uchebnik-aod/`.

Изпратете този адрес на участниците. На телефона: отварят го в Chrome → **Инсталиране на приложението** (или Safari → Сподели → **Добави към начален екран** на iPhone).

## Файлове

| Файл | Какво е |
|---|---|
| `index.html` | Целият учебник |
| `manifest.webmanifest` | Данни за инсталиране като приложение |
| `sw.js` | Работа без интернет |
| `icon-192.png`, `icon-512.png` | Икони |
| `.nojekyll` | Казва на GitHub да публикува файловете както са |
| `src/` | Изходни файлове за редактиране (не са нужни за сайта) |

## Обновяване

Когато получите нов `index.html`, качете го на мястото на стария (Add file → Upload files). В `sw.js` сменете `aod-v6` на следващ номер (`aod-v7`), за да видят телефоните новата версия.

## Режим учител

Настройки → Режим учител. Паролата се проверява в браузъра – тя пази от случаен достъп, но не е истинска защита.
